Detailed Description

Transport-independent interface to a Meade LX200 (or compatible) telescope.

The Meade LX200 ASCII protocol can be spoken either over a serial port or over a TCP/IP connection. TelescopeClientDirectLx200 talks to the telescope through this interface without needing to know which transport is in use.
