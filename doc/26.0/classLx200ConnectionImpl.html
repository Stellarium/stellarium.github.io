Detailed Description

template<class Transport>
class Lx200ConnectionImpl< Transport >

Implements the Meade LX200 command protocol on top of an arbitrary transport (Transport must be a Connection: either SerialPort or TcpConnection).

All the protocol logic lives here and is shared between the serial and the network variants; only the transport differs.
